Flagship project

Project Foundry

In active development · V2.6

A configurable, multi-industry synthetic data platform that generates realistic, structured datasets for analytics practice, dashboard building, experimentation, and business simulation. I’m building it as a scalable platform, not a pile of one-off scripts.

54passing tests
2industries supported
3data quality profiles
10–10krecords per run

How a dataset gets made

Request→Validate→Specify→Industry generator→Quality transforms→CSV export→Metadata→Regenerate

Every run gets its own ID and output folder, so nothing is overwritten. Seeds and fixed reference dates make any dataset reproducible from its saved JSON metadata.

Built Implemented

  • Modular Python engine with a generator factory and dataclass models
  • SaaS Customer and Finance Transaction datasets, including NGN, KES, GHS, ZAR, and EGP currency mapping
  • Clean, Realistic, and Messy profiles with controlled missing values and duplicates, with identifiers protected
  • Seed-based reproducibility and regeneration from metadata
  • Request validation and CLI workflows covered by Pytest

Building now V2.6

  • FastAPI and Pydantic backend wrapping the existing engine
  • React, TypeScript, and Vite frontend
  • Dashboard, generation forms, progress, and validation feedback
  • Run history, CSV downloads, and metadata access
  • Accessible, responsive interface

Vision Planned

  • More industry generators and reusable templates
  • Relational dataset generation
  • Dataset profiling, versioning, and lineage
  • Evidence-backed business scenarios and analytics training environments
