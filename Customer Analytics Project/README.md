# Customer Analytics Dashboard Project

## Project Overview

This project analyzes customer purchasing behavior, marketing performance, and customer support trends to uncover business insights and growth opportunities.

The project combines:

- Data cleaning in Excel
- SQL analysis in MySQL
- Dashboard development in Power BI
- Agile-style project tracking using Jira

# Project Objectives

The main goals of this project were to:

- Understand customer purchasing patterns
- Evaluate marketing channel performance
- Identify operational pain points
- Analyze customer satisfaction trends
- Build an interactive business intelligence dashboard

# Tools Used

- Excel: Data cleaning and preparation
- MySQL: SQL analysis
- Power BI: Dashboard development and visualization
- Jira: Project tracking and workflow management

# Key Insights

- Organic Search outperformed Instagram in conversion efficiency
- Late Delivery was the biggest customer complaint
- Lagos generated the highest share of total revenue
- VIP customers generated high-value purchases but weak retention
